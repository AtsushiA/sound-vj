# Audio VJ - パーティクルビジュアライザー

ブラウザで動作するVJソフトです。マイク入力に反応してパーティクルを生成し、リアルタイムでビジュアルエフェクトを楽しめます。

## 機能

- **オーディオ入力**: マイクからのリアルタイム音声入力
- **パーティクルシステム**: 音量に反応するパーティクル生成
- **エフェクト**: 重力、風、回転、トレイル、ブルーム効果
- **カラーシステム**: 5つのカラーモード（レインボー、炎、海、ネオン、カスタム）
- **プリセット機能**: 設定の保存・読み込み・削除
- **インタラクション**: マウスクリックでパーティクルバースト

## 使用方法

### 方法1: 直接ブラウザで開く
1. `index.html`をブラウザで開く
2. 「開始」ボタンをクリック
3. マイクアクセスを許可

**注意**: 一部のブラウザではHTTPでマイクアクセスが制限されます。

### 方法2: HTTPSサーバーで起動（推奨）
1. ターミナルで以下を実行:
   ```bash
   python3 server.py
   ```
2. ブラウザで `https://localhost:8443` にアクセス
3. 証明書の警告が出た場合は「詳細設定」→「localhost に進む」を選択
4. 「開始」ボタンをクリックしてマイクアクセスを許可

### 方法3: Node.jsサーバー（代替）
```bash
# http-serverをインストール
npm install -g http-server

# HTTPSサーバーを起動
http-server -S -C cert.pem -K key.pem -p 8443
```

## トラブルシューティング

### マイクアクセスが許可されない場合
1. **HTTPS接続を使用**: HTTPではマイクアクセスが制限されます
2. **ブラウザ設定を確認**: サイトの設定でマイクアクセスが許可されているか確認
3. **コンソールログを確認**: F12でデベロッパーツールを開き、エラーメッセージを確認

### 音が反応しない場合
1. **マイクが正常に動作しているか確認**
2. **感度設定を上げる**: 右パネルの「感度」スライダーを調整
3. **周波数範囲を変更**: 音楽の種類に応じて低音域/中音域/高音域を選択

### パフォーマンスが悪い場合
1. **パーティクル数を減らす**: 「数量」スライダーを下げる
2. **エフェクトを無効化**: ブルームやトレイルを無効にする
3. **ブラウザのハードウェアアクセラレーションを有効化**

## 操作方法

- **開始/停止**: マイク入力の開始・停止
- **マウスクリック**: クリック位置にパーティクルバースト
- **フルスクリーン**: 全画面表示の切り替え
- **プリセット**: 設定の保存・読み込み
